API Documentation

VERSION 0.2

Authentication

Public search needs no authentication. Browser administration uses an HttpOnly session and CSRF token; automation may use X-Admin-Token. Workers use a unique X-Worker-Token. Credentials are never accepted in query strings.

Administrative workflow

Create an explicit CIDR authorization, then submit a bounded job using a predefined profile. Search requests cannot create jobs. JSON and CSV passive imports require documented provenance.
